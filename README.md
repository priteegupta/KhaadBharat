# KHAAD BHARAT React/Vite Scaffold

This folder is the phase 3 migration starter for the KHAAD BHARAT website.

## What is here

- `src/App.jsx` for the first React shell
- `src/data/site.js` for page data and language seeds
- `src/data/content.json` for the shared content snapshot
- `src/pages/*` for page-level components
- `src/components/*` for reusable layout pieces
- `vite.config.js` and `package.json` ready for a future install

## Next step

When package tools are available, run:

```bash
npm install
npm run dev
```

Then we can begin moving the phase 2 content into real React components and route handlers.
